# lbagnato.github.io

Personal site of Luigi Bagnato, served by GitHub Pages at <https://www.luigibagnato.com>.

Plain HTML/CSS, no build step.

- `index.html` — page content and SEO/social meta tags
- `assets/css/style.css` — styles (light and dark)
- `assets/img/profile.jpg` — profile photo (square, ≥ 400×400; falls back to an "LB" monogram if missing)
- `assets/img/og-image.png` — 1200×630 link-preview image
- `CNAME` — custom domain

Text styled in amber italics (`class="ph"`) is a placeholder still to be filled in.

Preview locally: `python3 -m http.server` and open <http://localhost:8000>.
